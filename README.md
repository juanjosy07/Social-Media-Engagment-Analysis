# Social Media Engagement Analytics

A data analysis project exploring engagement patterns across 5,000 social media posts using Python.

## 📊 Overview

This project analyzes a dataset of social media posts to uncover insights about 
content performance, user behavior, and sentiment impact on engagement.

## 🛠️ Tools Used

- **Pandas & NumPy** — data cleaning and manipulation
- **Matplotlib & Seaborn** — static visualizations
- **Plotly** — interactive visualization

## 📁 What's Inside

- `Data_Analysis_using_Python.ipynb` — full analysis notebook, including:
  - Data import and setup
  - Data cleaning (missing values, duplicates, outlier correction)
  - Exploratory data analysis
  - Data wrangling and feature engineering
  - Statistical analysis
  - 13 visualizations (6 Matplotlib, 6 Seaborn, 1 Plotly interactive)
  - Final insights summary

## 🔑 Key Findings

- **Video** posts get the highest engagement, and **lifestyle** content performs best overall.
- **UAE, Australia, and France** show the highest engagement rates by country.
- **Negative-sentiment posts** unexpectedly outperform positive posts on engagement.
- Verified accounts show slightly higher engagement despite marginally lower average likes.

## 📌 Dataset

5,000 rows of social media post data including likes, comments, shares, impressions, 
follower counts, sentiment, and post metadata.
